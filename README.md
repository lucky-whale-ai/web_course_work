# Руф Профи — курсовой проект

Сайт строительной компании по [макету Figma](https://www.figma.com/design/fmZbCOwl6m1Hv3JpjNd73T/). Обычные HTML, CSS и JavaScript; база данных — JSON Server.

## Запуск

Установите Node.js 22 или новее, затем выполните в папке проекта:

```sh
npm install
npm start
```

Откройте [сайт](http://127.0.0.1:3000). Один сервер обслуживает страницы, файлы и API. Сборка не требуется. Для автоматической проверки: `npm test`.

## Структура

- `index.html` — входная страница.
- `css/` — оформление и адаптивная вёрстка.
- `js/` — страницы, обработчики событий, запросы к API и проверка форм.
- `assets/`, `fonts/` — изображения и шрифты с лицензиями.
- `server/` — запуск JSON Server, API и проверка прав доступа.
- `data/seed.json` — исходная демонстрационная база.
- `tests/` — проверки регистрации, авторизации, каталога и сервера.
- `qa/` — эталоны главной и наложение для сравнения с макетом.
- `docs/` — ссылки на макеты, источники и результаты проверок.

Страницы переключаются по ссылкам вида `#/projects`. Браузер загружает модули JavaScript напрямую, без сборщика.

## Возможности

Главная, страницы компании, направлений, лицензий, охраны труда и контактов; каталог из 30 объектов с поиском, фильтром, сортировкой и пагинацией. Регистрация, вход, личный кабинет, избранное, обращения и административная смена их статуса. Формы проверяются в браузере и на сервере; пароли хешируются.

В **«О компании → Настройки»** доступны русский, белорусский и английский языки, светлая и тёмная темы, режим для слабовидящих, размер текста 100/150/200%, три контрастные палитры и скрытие изображений. На телефоне настройки находятся в раскрывающемся меню. На внутренних страницах ссылка есть и в подвале. Выбор сохраняется после перезагрузки.

## Демонстрационные аккаунты

| Роль | Email | Пароль |
|---|---|---|
| Пользователь | user1@example.test | RoofUser!2025 |
| Пользователи 2–9 | user2@example.test … user9@example.test | RoofUser!2025 |
| Администратор | admin@example.test | RoofAdmin!2025 |

Исходная база содержит 10 пользователей, 30 объектов, 15 записей избранного у трёх пользователей и три обращения. При первом запуске создаётся `data/runtime.json`. Здесь сохраняются изменения; этот файл не включён в Git и не доступен по HTTP. Для отдельной базы можно указать путь в переменной окружения `DATA_FILE`. Существующие данные при запуске не сбрасываются.

Сообщения сохраняются в учебной базе и не отправляются реальной компании.
