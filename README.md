# Руф Профи — курсовой проект

Учебный сайт строительной компании по [макету Figma](https://www.figma.com/design/fmZbCOwl6m1Hv3JpjNd73T/). HTML, CSS и JavaScript без UI-фреймворков. Локальная база и API работают через JSON Server; Fetch API связывает интерфейс с сервером.

## Запуск

Нужны Node.js 22 или новее и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://127.0.0.1:5173. Сервер данных запускается вместе с сайтом на http://127.0.0.1:3001/api/health. Вход и сохранение данных требуют обоих процессов; простой просмотр index.html с диска не подходит.

```sh
pnpm test
pnpm build
```

`pnpm preview` показывает собранные статические файлы; для полной проверки функций запускайте `pnpm dev`. При размещении собранного сайта вместе с ним должен работать API `/api` на том же домене.

## Что реализовано

- Главная, о компании, направления, лицензии, каталог, детальная страница объекта, охрана труда, контакты и 404.
- Регистрация с проверками приложения В: возраст, телефон РБ, email, пять вариантов никнейма, ручной/автоматический пароль, блок-лист паролей, ручное подтверждение и прочтение соглашения.
- Вход, выход и серверная сессия; две роли. Пароли хешируются, доступ к данным проверяется API.
- Поиск, фильтр по направлению, сортировка и постраничный каталог из 30 объектов.
- Избранное, личный кабинет, обращения, административная смена статуса.
- Шесть слайдов главной, просмотр документов, диалоговые формы, уведомления, состояния загрузки и ошибок, карта офиса.
- Русский/английский, светлая/тёмная тема, режим доступности, три размера текста и палитры, скрытие изображений и сброс предпочтений.

Настройки и кабинет доступны из меню «О компании» на компьютере или из мобильного меню. На внутренних страницах эти ссылки также есть внизу.

## Данные

`data/seed.json` содержит 10 исходных пользователей, 30 проектов, 15 записей избранного у трёх пользователей и три обращения. Первые шесть объектов основаны на макете. Остальные явно обозначены как учебные. При первом локальном запуске создаётся `data/runtime.json`; этот файл не попадает в Git.

Для новой демонстрационной базы остановите сервер и запустите его с переменной `DATA_FILE`, указывающей на новый JSON-файл. Он будет создан из seed. Существующая база автоматически не сбрасывается. Перед ручным сбросом сохраните её копию.

## Сравнение с Figma

Эталоны главной находятся в `qa/reference-1440.png`, `qa/reference-1920.png`, `qa/reference-768.png`, `qa/reference-320.png`. В режиме разработки доступен http://127.0.0.1:5173/qa/compare.html: выбор ширины, прозрачность наложения, разница пикселей и измерение секций. Этот служебный экран не включается в сборку.

## Размещение

Для размещения используется Cloudflare Worker с тем же обработчиком API и хранилищем D1. Схема и миграции находятся в `db/` и `drizzle/`; сборка выдаёт `dist/client`, `dist/server/index.js` и метаданные `dist/.openai`. Локальный JSON Server остаётся отдельным вариантом запуска для демонстрации требований задания.

Проект Sites привязан в `.openai/hosting.json`. Публикуется сохранённая версия из конкретного коммита, вместе с собранным Worker, статическими файлами и миграциями. По умолчанию доступ к публикации предоставлен только владельцу. Ссылка и результат проверки размещения передаются отдельно после успешной публикации. Для показа преподавателю можно использовать локальный запуск; открытие внешнего доступа требует настройки аудитории сайта.
