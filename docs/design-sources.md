# Источники дизайна и контроль вёрстки

Исходный макет: https://www.figma.com/design/fmZbCOwl6m1Hv3JpjNd73T/?node-id=0-1

Desktop-эталоны сохранены: 1440 px — `6:95`, 1920 px — `75:3917`.
Адаптивные копии находятся на отдельной странице «Курсовая — адаптивы» (`4214:3840`).

Изображения и иконки экспортированы из исходного макета. Экспорты нескольких изображений из design context были пустыми: вместо них используются прямые экспорты исходных графических слоёв (`hero.png`, `sector-*.png`). Тексты и элементы интерфейса реализуются HTML/CSS.

Golos Text Regular/Medium: https://github.com/googlefonts/golos-text, лицензия OFL в `public/fonts/Golos-OFL.txt`. У исходного Figma-файла старые имена `Golos / Text Regular` и `Golos / Text Medium`. Исходные семейства недоступны инструменту Figma. В новых адаптивах применяется доступный Golos Text. Проверка шести надписей выявила нулевую разницу ширины у пяти и разницу 1 px у слова «Контакты». Полная идентичность очертаний не заявляется; проверка наложением обязательна.

PT Root UI Bold: оригинальный пакет Paratype из архива https://github.com/font-archive/PT-Root-UI/tree/431cf1e1b77f1a85cb35242d88e86369fd08676f/Bold. Лицензия OFL сохранена в `public/fonts/PT-Root-UI-LICENSE.txt`. Локально используется WOFF2 из пакета.

Вёрстка главной проверяется в исходном состоянии (RU, светлая тема, первый слайд, закрытые меню и окна). Дополнительные настройки доступны из выпадающего меню «О компании» и мобильного меню. Исходные изображения и тексты на главной сохраняются для сравнения; дополнительные демонстрационные данные отдельно описываются в README.

Статус: подготовка ресурсов и адаптивов. Фактическое сравнение готовой страницы ещё не выполнено.
