# Источники дизайна

Источник: [Figma «РуфПрофи»](https://www.figma.com/design/fmZbCOwl6m1Hv3JpjNd73T/).

Оригинальные эталоны главной сохранены: 1440 — `6:95`, 1920 — `75:3917`, мобильный исходник375 — `60:2072`. Новые адаптивы: 320 — `4214:3841`, 768 — `4237:4106` на странице «Курсовая — адаптивы».

Графика экспортирована из исходного файла. `sector-*.png` содержат только графические слои и фон карточек, без текста и интерфейса. Для каждой ширины экспортировано соответствующее кадрирование. Все заголовки, списки и элементы управления реализованы HTML/CSS. Главная не заменена снимком макета.

`footer-320.png`, `footer-768.png`, `footer-1440.png` и `footer-1920.png` — только фотографический фон баннера подвала, без надписей. `map-1920.png` — графика карты из исходного широкого экрана, экспортированная с его границами кадрирования. В Figma вспомогательные графические слои находятся на странице «Ресурсы — экспорт графики».

Для точных метрик в браузере используются старые `Golos_Text_Regular.woff2` и `Golos_Text_Medium.woff2` версии1.000, найденные среди публичных ресурсов [сайта компании](https://roof-prof.ru/company/). Современный Golos Text имеет другие метрики. Лицензия OFL сохранена в fonts/Golos-OFL.txt. В новых текстовых слоях Figma используется доступное инструменту семейство Golos Text; исходные desktop-слои не заменены.

PT Root UI Bold взят из [архива исходного пакета Paratype](https://github.com/font-archive/PT-Root-UI/tree/431cf1e1b77f1a85cb35242d88e86369fd08676f/Bold). Лицензия сохранена в fonts/PT-Root-UI-LICENSE.txt. Шрифт недоступен инструменту редактирования Figma, поэтому существующие надписи логотипа сохраняются.

Исключение в адаптивной главной: названия лицензий используют семейство `Golos Adaptive`, связанное с имеющимся `GolosText-Medium.ttf`. Оно соответствует новым текстовым слоям адаптивов Figma; исходная типографика остальных блоков сохранена. Номера свидетельств объединены неразрывными фрагментами, чтобы переносить их целиком.

В новом фрейме 320 исправлено положение группы надписи баннера подвала: X = 16, Y = 60 относительно баннера. Исходные фреймы 375/1440/1920 не изменялись. Эталон `qa/reference-320.png` обновлён после этой коррекции.

Дизайн главной опирается на Figma. Актуальный сайт компании использован для поиска шрифтов, не как замена макету. Текст об истории компании сверялся с исходным экраном «О компании».

Новые экраны остальных страниц допускают расхождения с исходником по просьбе пользователя. Их перенос из вёрстки в Figma выполняется отдельными редактируемыми слоями и проверяется по размерам; такой перенос не служит доказательством точности главной.

Подтверждённые проверки и оставшиеся действия перечислены в QA.md.

Для карточек документов используются WebP-превью до 600×800 px; для просмотра — версии до 2000×2600 px. Полноразмерные оригиналы сохранены отдельно среди материалов курсовой.
