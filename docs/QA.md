# Проверки сайта

Обновлено: 10.09.2026. Записка курсовой отложена по просьбе пользователя.

## Подтверждено

- 7 автоматических проверок API прошли: возраст и календарь, поля регистрации, роль и хеширование пароля, дубликаты и сессия, права на избранное/обращения и CSRF, каталог, некорректные типы входных данных.
- В браузере создан тестовый аккаунт qa.coursework.20260909@example.test. Проверены пять попыток никнейма, обязательное прочтение соглашения, запрет вставки повторного пароля и блокировка неполной формы.
- Пользователь нашёл объект 10 совместным поиском и фильтром, сохранил его в избранное, отправил обращение. Администратор изменил статус на «Завершено». Повторный вход пользователя подтвердил сохранение избранного и статуса.
- Исправлены скрытые элементы формы, подписи полей с ошибками, состояние генератора пароля, закрытие мобильного меню и удержание клавиатурного фокуса.
- Проверены RU light и EN dark на 320 px: главная, о компании, направления, лицензии, каталог, объект 10, охрана труда, контакты, регистрация, кабинет, настройки. После исправления длинного заголовка направлений ширина страницы равна доступной ширине окна (305 px при обычной полосе прокрутки).
- Проверены крупный текст 200%, контрастная тема и скрытые изображения на тех же страницах. Исправлено переполнение сетки регистрации, повторный замер 305/305 px.
- Для переноса страницы направлений в Figma дополнительно проверена ширина без полосы прокрутки: документ и #app имеют client/scroll width 320/320 px.
- WebMCP search_projects зарегистрирован, корректный поиск вернул объект 10, page=-1 намеренно отклонён.
- Сборка Vite и Worker прошла. Служебный запуск сборки Sites не нашёл Windows-команду; прямой pnpm build завершился успешно.

## Главная: геометрия

Ширины 1440/1920 — исходные эталоны Figma; 768/320 — новые адаптивы. Эталоны PNG и локальный инструмент наложения находятся в qa/.

Повторный замер всех шести секций выполнен на всех четырёх ширинах. Целочисленные координаты совпали с таблицей; дробная высота адаптивного подвала в браузере отличается примерно на 0,006 px вследствие округления.

Наложением проверены первый экран, деятельность, статистика, объекты, лицензии и подвал на 320/768/1440/1920. Дополнительно проверены нижние карточки деятельности, карта и конец подвала на 320, конец подвала на 768. Исправлены выравнивание счётчика и кнопок, переносы названий сертификатов, кадрирование карты на 1920 и фон подвала на каждой ширине.

Снимки отдельных секций находятся в qa/evidence. Это JPEG-снимки браузера для визуальной проверки, а не материал для численного сравнения пикселей. Некоторые широкие снимки обрезаны по размеру окна просмотра; геометрия измерялась при полной ширине 1920. PNG-эталоны в qa/reference-*.png экспортированы непосредственно из Figma. Абсолютное равенство каждого пикселя не заявляется: растрирование шрифтов Figma и браузером может различаться.

Главная в режиме доступности собрана в раскрывающиеся разделы: вводный текст и четыре раздела видны без длинного пролистывания, содержимое открывается с клавиатуры. На 1440 px полная высота начального состояния — 2037 px. Повторно проверены 320 px, текст 200%, контрастная тема и скрытые изображения: закрытые разделы и открытые лицензии не создают горизонтального переполнения (305/305 px с обычной полосой прокрутки).

- Подготовлены мудборд, доска состояний и 51 прототип: по 17 схем на 1440/768/320. Количество и размеры проверены после переноса в Figma.
- Последняя сборка после исправления соглашения прошла. Автоматические проверки API — 7 из 7; серверный код после них не менялся.

## Размещение

Инструкция локального запуска готова. Сборка подготовлена для Sites с Worker и D1. Результат публикации и проверка размещённого API фиксируются отдельно при размещении; локальные проверки не доказывают доступность опубликованной версии.

Блок-лист дополнен 200 опубликованными позициями за 2023 год; все записи и сложные распространённые комбинации проверены автоматическим тестом. Происхождение и ограничения копии описаны в password-policy.md.

Сканы лицензий сохранены без изменений в design-assets/licenses. Карточки используют превью WebP (суммарно около 0,9 МБ), окно документа — увеличенную версию. Это также устранило превышение лимита переноса страницы в Figma.
