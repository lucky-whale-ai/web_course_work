# Проверки сайта

## Автоматические проверки

`npm test` проверяет ограничения регистрации (включая календарные даты, возраст 16+ и список распространённых паролей), вход и выход, роли, доступ к чужим данным, каталог и обработку некорректных запросов.

## Сравнение главной

Эталоны Figma сохранены в `qa/reference-320.png`, `qa/reference-768.png`, `qa/reference-1440.png`, `qa/reference-1920.png`. Координаты и высоты секций записаны в `qa/geometry.json`. Наложение доступно по адресу `/qa/compare.html` после запуска сайта.

Размеры секций сверяются при стандартных настройках: русский язык, светлая тема, текст 100%, режим для слабовидящих выключен. Совпадение размеров само по себе не доказывает совпадение каждого пикселя: текст и изображения дополнительно проверяются наложением с эталоном.

## Функциональные проверки

Проверяются каталог и фильтры, авторизация, личный кабинет, избранное, обращения и административная панель. Для настроек проверяются смена языка, тема, режим для слабовидящих, увеличение текста, палитры, скрытие изображений и сохранение выбора после перезагрузки.

Адаптивы внутренних страниц проверяются на ширинах 320 и 768 px. Макеты всех страниц и ссылки на них перечислены в [карте экранов](design-map.md).
## Проверка после упрощения структуры (11.09.2026)

- `npm test`: 8 из 8 проверок прошли. Дополнительно проверены загрузка HTML/CSS/JS, изображений и шрифтов, работа API с того же адреса и запрет чтения базы, серверного кода и обхода каталогов.
- Координаты и высоты всех шести секций главной совпали с сохранёнными значениями на 320, 768, 1440 и 1920 px.
- На 320 px проверены английский язык, тёмная тема, режим для слабовидящих, текст 200%, скрытие изображений и сохранение настроек после перезагрузки. Горизонтального переполнения страницы нет.
- Исправлен цвет подписи выбранных кнопок в режиме для слабовидящих. Контраст проверен для чёрно-белой, инверсной и голубой палитр.
- После переноса в браузере проверены поиск «Самарская» вместе с фильтром «Нефтегазовый сектор» (7 объектов), вход демонстрационного пользователя, загрузка его избранного и выход.
