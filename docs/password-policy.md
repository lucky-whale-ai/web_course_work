# Проверка распространённых паролей

Регистрация исключает список 2023 года дополнительно к проверке длины, обоих регистров, цифры и специального символа. Проверка одинакова в браузере и API.

В `js/common-passwords.js` сохранены 200 позиций опубликованной копии списка NordPass за 2023 год. Используется весь список, чтобы покрыть требуемый TOP100, в том числе записи после исключения служебных значений UNKNOWN и звёздочек. Повторы в исходных позициях сохранены; Set при проверке устраняет их. Существующий дополнительный набор очевидно слабых паролей также сохранён.

Источник данных: [iDrop News, Avoid These 200 Most Common Passwords of 2023, 11.01.2024](https://www.idropnews.com/news/avoid-these-200-most-common-passwords-of-2023/205063/). Это вторичная публикация списка со ссылкой на NordPass, а не самостоятельно проведённое исследование. [Текущая страница NordPass](https://nordpass.com/most-common-passwords-list/) уже показывает более новый год. PDF с `top-200-2023` в адресе оказался таблицей 2019–2022 и не использован как подтверждение 2023.

Автоматическая проверка проходит по всем 200 строкам. Отдельно проверяются сложные по форме, но распространённые пароли Pass@123, Aa@123456, Demo@123, Password@123 и Welcome@123.
